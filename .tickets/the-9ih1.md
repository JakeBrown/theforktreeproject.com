# Add staff review UI for volunteer registrations

Build a protected staff workflow to review, search, export, and manage online volunteer registrations stored in D1. This is intentionally deferred from the initial public registration launch. Access controls must be reviewed before exposing emergency contact, date-of-birth, accessibility, medical, or WWCC information.

## Acceptance Criteria

Authorised staff can find and review registrations without exposing sensitive data to unauthorised users; access, audit, export, deletion, empty/error, and responsive states are defined and tested; the UI follows the approved retention policy.
