# Lock page scrolling behind admin dialogs

Prevent the underlying admin page from scrolling while any detail or day-list dialog is open. Support stacked dialogs and restore the original scroll position only after the final dialog closes, including Escape-key dismissal.


## Notes

**2026-08-21T03:07:22Z**

Added document scroll locking for every admin dialog. The lock freezes the page at its current position, remains active across stacked day/detail dialogs, unlocks only after the final dialog closes, and restores scroll after native focus restoration settles. Verified close buttons and Escape dismissal in local Wrangler/Chromium; production build and git diff checks pass.
