# Use emoji instead of colour for admin statuses

Admin status badges, calendar chips/counts, registration flags and the MailerLite badge use emoji on neutral backgrounds instead of coloured dots: ✅ signed in, 👋 signed out, 📅 scheduled, ⏰ automatic; ✅/⚠️/⏳ for MailerLite. Calendar feed titles switch to the same emoji (Jake's choice).
