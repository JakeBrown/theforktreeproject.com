So this is a BIG project. It’s a journey, and the road ahead is long. 

The first step on the journey needs to a be a stock take, an assessment of what we have in front of us so that we can work out what needs to be done. Perhaps working back from the desired endpoint is a good way to start. 

So. The ultimate goal is the revegetation and rewilding of this site. 

To achieve this we need trees in the ground.

To plant the trees we need stakes, corflutes, mattocks and mallets.

To do the planting we need volunteers.

To put the volunteers and equipment to use we need to source the saplings.

To store all these things we need a usable shed.

To water the plants we need to harvest rainwater in water tanks.

To get the water to the saplings we need to set up some form of irrigation system.

To power tools we need solar power.

To move around the property we need driveable tracks.

To protect the saplings from kangaroos we need serious fencing.

To prepare much of the site for planting we need to clear the building waste that has been dumped here.

And breathe…

That’s an exhausting first step. Next step is to work out the order…
